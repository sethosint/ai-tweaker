# Как безопасно проверить AI Tweaker без виртуальной машины

Виртуальная машина не нужна: всё, что меняет AI Tweaker, обратимо, а перед изменениями создаётся точка восстановления Windows. Ниже — порядок, при котором любой шаг можно отменить.

## 0. Сначала — демо-режим, без изменений в системе

Откройте `src/AITweaker.App/wwwroot/index.html` в обычном браузере. Интерфейс запустится с симулированными данными («Демо» в шапке): можно пройти все вкладки, «применить» профиль, посмотреть окна подтверждения и перезагрузки. Система при этом не меняется.

## 1. Подготовка (2 минуты)

1. Проверьте, что защита системы включена: **Win + R → `SystemPropertiesProtection`** → диск C: → «Защита: Включено». Если выключено — «Настроить → Включить защиту системы», 5–10 % места.
2. В AI Tweaker: **настройки (значок в шапке) → «Точка восстановления перед применением»** — включено (по умолчанию).
3. Закройте игры и важные программы: после части твиков нужна перезагрузка.

## 2. Сканирование — ничего не меняет

Запустите `AITweaker.exe` (он сам попросит права администратора). Вкладка **«Пульт»** только читает систему: железо, датчики, найденные проблемы. На этом этапе ничего не применяется.

## 3. Применяйте по шагам

1. **Авто-тюнинг → профиль «Безопасный» → «Применить»**. Перезагрузитесь, поиграйте, проверьте звук, сеть, мышь, принтер.
2. Если всё в порядке — профиль **«Баланс»**, затем **«Производительность»**. После каждого — та же проверка.
3. **«Отключите то, чем не пользуетесь» → «Выбрать функции»**: оставьте «Пользуюсь» у всего, что нужно. Каждая строка подписана — что перестанет работать.
4. **«Экстрим»** — только если понимаете, что делают такие твики: каждый важный спрашивает подтверждение отдельно.

Твики, которые отключают что-то важное, никогда не применяются молча: появляется окно «Что вы потеряете» с кнопками «Да, применить» / «Нет, пропустить».

## 4. Если что-то пошло не так

| Ситуация | Что делать |
|---|---|
| Не работает одна вещь (Bluetooth, принтер, поиск…) | **Откат** → найдите твик → «Откатить». Возвращаются исходные значения Windows, сохранённые перед изменением |
| Непонятно, какой твик виноват | **Откат → «Откатить всё»** |
| Пропала картинка после смены разрешения | Ничего не нажимайте: через 15 секунд прежний режим вернётся сам |
| Windows загружается, но ведёт себя странно | **Win + R → `rstrui`** → точка «AI Tweaker …» |
| Windows не загружается | Три раза прервите загрузку (или Shift + «Перезагрузка») → **Поиск и устранение неисправностей → Дополнительные параметры → Восстановление системы** |

Копии исходных значений лежат в `C:\ProgramData\AITweaker\backups`, журнал — в `C:\ProgramData\AITweaker\logs`.

## 5. Внешний вид

Вкладка «Твики» → категория «Внешний вид AI Tweaker»: тёмная тема, чёрные панель задач и «Пуск», чёрный рабочий стол, экран блокировки. Каждый пункт откатывается отдельно. Классический «Пуск» в стиле Windows 7 требует Open-Shell — его можно поставить на вкладке **«Установка»**, после установки AI Tweaker сам предложит его настроить.

## 6. Плейбук для AME Wizard

Плейбук (`Образ → Плейбук для AME Wizard`) меняет систему напрямую, без резервных копий AI Tweaker, поэтому первым шагом сам создаёт точку восстановления **«AI Tweaker playbook»**. Вернуть всё — через `rstrui` к этой точке. Отдельные пункты внешнего вида можно вернуть и в «Параметры → Персонализация».

## 7. Образ и флешка

- Собирайте образ на любом ПК: сборка идёт в отдельной папке, исходный ISO не меняется.
- Для флешки берите накопитель, данные на котором не нужны, — он будет полностью стёрт. Программа показывает только USB-диски и просит ввести номер диска.
- Установка с флешки **не** размечает диск сама: на каком диске ставить Windows, вы выбираете вручную. Если не уверены — отключите остальные диски на время установки.

## 8. Переустановка без флешки

`Образ → Переустановка Windows без флешки` запускает штатный Windows Setup из работающей системы (`setup.exe /auto clean | dataonly | upgrade`):

- **Всё — восстановление** сохраняет программы и файлы и чинит систему — самый безопасный вариант, чтобы проверить, как это работает.
- **Только личные файлы** оставляет документы, рабочий стол и загрузки.
- **Ничего** — чистая установка: перед ней перенесите важное на другой диск или в облако. Программа просит ввести «ДА».

Образ не может быть старее установленной Windows — AI Tweaker проверяет это до запуска. Ставить на другой диск, заново размечать диск или откатываться на старую версию можно только с флешки.
