# Как отключить Hyper-V

Компоненты виртуализации Windows (Hyper-V, «Платформа виртуальной машины», «Песочница») мешают части эмуляторов и старым версиям VirtualBox/VMware и держат лишние службы. Если вы ими не пользуетесь, их можно выключить.

**Что перестанет работать:** WSL 2, Docker Desktop, «Песочница Windows», виртуальные машины Hyper-V, эмуляторы Android, которые работают через Hyper-V.

**Что остаётся как было:** «Изоляция ядра → Целостность памяти» и другие функции безопасности Windows. AI Tweaker их не выключает. Если целостность памяти включена, Windows продолжит запускать гипервизор для неё — так и должно быть.

Отключать виртуализацию в BIOS (SVM / Intel VT-x) **не нужно**.

## Способ 1. Через AI Tweaker (рекомендуется)

1. **Оптимизация** → вопрос **«Отключить Hyper-V и виртуализацию Windows»** → «Отключить».
2. Перезагрузите компьютер, когда появится окно перезагрузки.

AI Tweaker запоминает, какие компоненты были включены, и при откате включает обратно ровно их.

## Способ 2. Вручную, через окно компонентов

1. Нажмите **Win + R**, введите `optionalfeatures`, нажмите Enter.
   (Или: **Параметры → Система → Дополнительные компоненты → Другие компоненты Windows**.)
2. Снимите галочки:
   - **Hyper-V** (есть только в Pro / Enterprise / Education);
   - **Платформа виртуальной машины**;
   - **Платформа низкоуровневой оболочки Windows**;
   - **Песочница Windows**.
3. Нажмите **ОК**, дождитесь окончания и перезагрузите компьютер.

## Способ 3. Одной командой в PowerShell

Откройте **Терминал (администратор)** и вставьте:

```powershell
'Microsoft-Hyper-V-All', 'VirtualMachinePlatform', 'HypervisorPlatform', 'Containers-DisposableClientVM' |
  ForEach-Object { Disable-WindowsOptionalFeature -Online -FeatureName $_ -NoRestart -ErrorAction SilentlyContinue | Out-Null }
Restart-Computer
```

Ошибка про `Microsoft-Hyper-V-All` в Windows Home — нормально: этого компонента там просто нет.

## Как вернуть всё обратно

- В AI Tweaker: **Откат** → «Отключить Hyper-V…» → «Откатить».
- Вручную: включите те же компоненты в `optionalfeatures` и перезагрузитесь.
