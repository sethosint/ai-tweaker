# Как отключить Hyper-V

Когда гипервизор Windows включён, сама Windows работает поверх него. Это немного добавляет задержек и мешает части эмуляторов и старым версиям VirtualBox/VMware. Если вы не пользуетесь виртуализацией, гипервизор лучше выключить.

**Что перестанет работать:** WSL 2, Docker Desktop, «Песочница Windows», виртуальные машины Hyper-V, эмуляторы Android, которые работают через Hyper-V. Вместе с гипервизором выключаются и функции безопасности на его основе: «Изоляция ядра → Целостность памяти» (VBS/HVCI) и Credential Guard. Это осознанный компромисс: чуть меньше защиты ради отклика.

Отключать виртуализацию в BIOS (SVM / Intel VT-x) **не нужно** — достаточно шагов ниже.

## Способ 1. Через AI Tweaker (рекомендуется)

1. **Авто-тюнинг** → блок «Отключите то, чем не пользуетесь» → **«Выбрать функции»**.
2. У строки **«Виртуализация: WSL, Docker, эмуляторы Android, «Песочница»»** переключатель «Пользуюсь» должен быть выключен. Нажмите **«Отключить ненужное»**.
3. Перезагрузите компьютер, когда появится окно перезагрузки.

То же самое — твик **«Отключить Hyper-V и виртуализацию Windows»** (`system.hyperv.off`) на вкладке «Твики». AI Tweaker запоминает, какие компоненты были включены, и при откате включает обратно ровно их.

## Способ 2. Вручную, через окно компонентов

1. Нажмите **Win + R**, введите `optionalfeatures`, нажмите Enter.
   (Или: **Параметры → Система → Дополнительные компоненты → Другие компоненты Windows**.)
2. Снимите галочки:
   - **Hyper-V** (есть только в Pro / Enterprise / Education);
   - **Платформа виртуальной машины**;
   - **Платформа низкоуровневой оболочки Windows**;
   - **Песочница Windows**.
3. Нажмите **ОК** и дождитесь окончания.
4. Откройте **Терминал (администратор)** и выполните:
   ```
   bcdedit /set hypervisorlaunchtype off
   ```
5. Перезагрузите компьютер.

## Способ 3. Одной командой в PowerShell

Откройте **Терминал (администратор)** и вставьте:

```powershell
'Microsoft-Hyper-V-All', 'VirtualMachinePlatform', 'HypervisorPlatform', 'Containers-DisposableClientVM' |
  ForEach-Object { Disable-WindowsOptionalFeature -Online -FeatureName $_ -NoRestart -ErrorAction SilentlyContinue | Out-Null }
bcdedit /set hypervisorlaunchtype off
Restart-Computer
```

Ошибка про `Microsoft-Hyper-V-All` в Windows Home — нормально: этого компонента там просто нет.

## Как проверить, что гипервизор выключен

После перезагрузки выполните в PowerShell:

```powershell
(Get-CimInstance Win32_ComputerSystem).HypervisorPresent
```

- `False` — гипервизор выключен, всё получилось.
- `True` — он всё ещё запускается.

Или: **Win + R → `msinfo32`** → «Сведения о системе», в самом низу. Строка «Обнаружена низкоуровневая оболочка…» означает, что гипервизор работает; четыре строки «Hyper-V — …: Да» — что он выключен. Там же «Безопасность на основе виртуализации» должна быть «Не включено».

## Если `HypervisorPresent` всё ещё `True`

Гипервизор запускает что-то ещё:

1. **Целостность памяти.** «Безопасность Windows → Безопасность устройства → Сведения об изоляции ядра → Целостность памяти» — выключите и перезагрузитесь. В AI Tweaker это твик «Отключить VBS и целостность памяти» (спрашивает подтверждение).
2. **Credential Guard / VBS по политике** (корпоративные ПК): если ПК управляется организацией, отключать это без администратора не стоит.
3. Проверьте, что команда `bcdedit` выполнилась без ошибки: `bcdedit /enum {current}` должна показывать `hypervisorlaunchtype Off`.

## Как вернуть всё обратно

- В AI Tweaker: **Откат** → твик «Отключить Hyper-V…» → «Откатить».
- Вручную: включите те же компоненты в `optionalfeatures`, затем `bcdedit /set hypervisorlaunchtype auto` и перезагрузка.
