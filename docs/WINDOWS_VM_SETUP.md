# Виртуальная машина Windows 11 для тестов AI Tweaker

Зачем: твики меняют реестр, службы, драйверы и загрузчик. На виртуалке можно применять всё подряд, проверять откат и за секунду возвращаться к чистой системе через снапшот. Если запустить в ней Claude Code, Claude сможет сам собирать программу, запускать её и проверять результат.

> На виртуальной машине нет настоящей видеокарты и сетевой карты, поэтому аппаратные твики (прерывания, MSI, BCD, параметры NIC) программа там **сознательно пропускает**. Их итоговая проверка возможна только на реальном ПК: перед этим создаётся точка восстановления, а откат возвращает исходные значения.

## Вариант A — Hyper-V (Windows 10/11 Pro, Enterprise, Education)

1. **Включить Hyper-V.** PowerShell от имени администратора:
   ```powershell
   Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All
   ```
   Перезагрузите ПК. Виртуализация (SVM / VT-x) должна быть включена в BIOS.
2. **Скачать ISO Windows 11** с <https://www.microsoft.com/software-download/windows11> («Загрузить образ диска (ISO)»). Если сайт недоступен в вашем регионе, используйте VPN или вкладку «Образ» в AI Tweaker.
3. **Создать ВМ:** «Диспетчер Hyper-V» → «Создать» → «Виртуальная машина»:
   - Поколение: **2**;
   - память: **8192 МБ**, динамическую память выключить;
   - сеть: **Default Switch**;
   - диск: **80 ГБ**;
   - установка: из скачанного ISO.
4. **До первого запуска:** правый клик по ВМ → «Параметры»:
   - «Безопасность» → включить **безопасную загрузку** (шаблон *Microsoft Windows*) и **доверенный платформенный модуль (TPM)**;
   - «Процессор» → **4** виртуальных процессора или больше;
   - «Контрольные точки» → «Стандартные».
5. **Установить Windows 11 Pro.** Чтобы не входить в учётную запись Microsoft, на экране сети нажмите «У меня нет интернета». Если ISO записан на флешку через AI Tweaker, это не потребуется: там уже есть `autounattend.xml` с локальной учётной записью.
6. **Сразу после установки сделать контрольную точку** «Чистая»: правый клик по ВМ → «Контрольная точка». Откат: правый клик по точке → «Применить».
7. Для общего буфера обмена включите «Вид» → «Расширенный сеанс».

## Вариант B — VirtualBox (подходит и для Windows Home)

1. Установите VirtualBox **7.1 или новее** с <https://www.virtualbox.org>.
2. «Создать» → тип *Microsoft Windows*, версия **Windows 11 (64-bit)**, укажите ISO, снимите галочку «Пропустить автоматическую установку», если хотите ставить вручную.
3. Память **8192 МБ**, процессоры **4**, диск **80 ГБ**. Для Windows 11 VirtualBox сам включает EFI, Secure Boot и TPM 2.0. Проверьте это в «Система» → «Материнская плата».
4. После установки: «Устройства» → «Подключить образ диска Дополнений гостевой ОС» и установите их (общий буфер, нормальное разрешение экрана).
5. «Машина» → «Сделать снимок» → «Чистая».

## Подготовка ВМ для работы Claude

Все команды выполняются внутри виртуалки, в PowerShell.

1. **Git и .NET 10 SDK:**
   ```powershell
   winget install --id Git.Git -e
   winget install --id Microsoft.DotNet.SDK.10 -e
   ```
   После установки откройте новое окно PowerShell.
2. **Claude Code** (официальный установщик для Windows):
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
   Можно вместо этого поставить приложение **Claude Desktop** с <https://claude.ai/download>.
3. **Репозиторий:**
   ```powershell
   git clone https://github.com/sethosint/ai-tweaker.git
   cd ai-tweaker
   git checkout claude/ai-tweaker-windows-5r13yi
   ```
4. **Подключить сессию к приложению Claude.** В папке репозитория выполните:
   ```powershell
   claude remote-control
   ```
   При первом запуске войдите в аккаунт Claude. Сессия появится в приложении Claude Code (на телефоне, в вебе или в desktop). Напишите в ней, что нужно протестировать, и Claude будет работать прямо в виртуалке: собирать, запускать, читать логи и проверять откат.

   Облачная сессия (как эта) подключиться к вашему компьютеру не может, поэтому тестирование на Windows идёт в отдельной локальной сессии.

## Что проверить в ВМ (план для Claude)

1. `dotnet test tests/AITweaker.Core.Tests` и `dotnet publish src/AITweaker.App -c Release -o publish`.
2. Запустить `publish\AITweaker.exe` от имени администратора и проверить, что сканирование правильно определило CPU, память, диск, монитор и Windows.
3. Профиль «Безопасный» → «Применить». Проверить статусы и логи в `C:\ProgramData\AITweaker\logs`.
4. Профиль «Экстрим» → применить → перезагрузиться → убедиться, что система загружается и работает.
5. «Откат» → «Откатить всё». Проверить, что значения в реестре и службы вернулись к исходным.
6. «Дебloat»: удалить рекомендованные приложения и убедиться, что Store и Xbox спрашивали подтверждение.
7. Применить твик с перезагрузкой (например, «Отключить динамический тик ядра») → должно появиться окно автоматической перезагрузки с отсчётом. «Отложить» → в шапке горит «⟳ Перезагрузка»; после перезапуска Windows значок пропадает.
8. Категория «Внешний вид AI Tweaker» → применить: тёмная тема, янтарный акцент, наши обои и экран блокировки, тема «AI Tweaker» в Параметрах. Затем откатить и проверить, что вернулись исходные обои и цвета.
9. «Образ»: выбрать ISO Windows 11 → «Что будет в образе» → «Собрать образ» (нужно ~25 ГБ свободного места и 20–60 минут). Проверить лог: версия Windows, встроенное KB, количество вшитых значений реестра. Готовую папку `C:\ProgramData\AITweaker\image\iso` можно превратить в ISO (`oscdimg` из Windows ADK) и поставить во второй ВМ — после первого входа AI Tweaker должен запуститься сам.
10. После проверок вернуться к контрольной точке «Чистая».

Флешку внутри Hyper-V создать не получится: USB не пробрасывается. Этот модуль проверяется на реальном ПК или в VirtualBox с пробросом USB.
