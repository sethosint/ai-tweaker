## AI Tweaker для Windows 11

Настраивает Windows под ваш компьютер: сам определяет железо и применяет то, что подходит именно ему. Всё, что отключает нужное, спрашивается отдельно. Всё обратимо.

### Как установить

1. Скачайте **AITweaker.exe** ниже, в блоке «Assets».
2. Запустите его. Установка не нужна: это один файл, его можно держать где угодно, например на рабочем столе. Программа сама попросит права администратора.
3. Windows может показать синее окно «Windows защитила ваш компьютер», потому что у файла нет платной цифровой подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. Некоторые антивирусы настороженно относятся к любым твикерам, потому что те меняют системные настройки. Если файл скачан отсюда, с GitHub, его можно добавить в исключения.

Нужна Windows 10 2004+ или Windows 11 x64. WebView2 уже есть в Windows 11; .NET ставить не нужно.

### С чего начать

- **Пульт**: что найдено на вашем ПК, датчики, проблемы.
- **Авто-тюнинг**: сначала профиль «Безопасный», затем «Баланс» или «Производительность».
- **Откат**: вернуть любой твик или все сразу. Перед изменениями создаётся точка восстановления Windows.

Подробно о том, как проверить всё безопасно: [docs/TESTING.md](https://github.com/sethosint/ai-tweaker/blob/main/docs/TESTING.md).
